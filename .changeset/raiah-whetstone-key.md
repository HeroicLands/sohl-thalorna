**Raiah's whetstone loses a key it no longer needs**

Raiah Sekmet'â carried two whetstones, and the ad-hoc one was given a
`system.shortcode` so the second could be told from the first. The pair has since
been consolidated into a single entry, which leaves the key naming nothing — an
inline item is identified by the note that declares it, not by a shortcode, and a
spare one invites a reference that would resolve to the wrong thing.

No compiled document changes shape: the whetstone is the same item with the same
weight, value and durability, and nothing referenced the key.
