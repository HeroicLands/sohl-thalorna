**The eight domains take Kheperi names instead of Egyptian loanwords.**

The first pass named the domains with bare dictionary borrowings — `mekhat`, `isfet`, `aten`, `duat`,
`kemet`, `deshret`, `ren`, `khat` — inside a setting that everywhere else _coins_ its vocabulary.
Each domain now carries a name built, where the material exists, from words already attested in the
Ta'Kheperu tree and joined in the corpus's own style:

| Domain         | Gloss                 | Built from                                              |
| -------------- | --------------------- | ------------------------------------------------------- |
| **Maat'ken**   | the Truth that Judges | _maat_ (Set-Maat, "Place of Truth") + Kenbet, the court |
| **Sefút**      | the Unmaking          | a pure coinage — see below                              |
| **Aten'ré**    | the Disk in its Heat  | _aten_ (Maru-Aten)                                      |
| **Imnetáu**    | the Westward Road     | _imnet_ (Khaut-Imnet, "Tombs of the West")              |
| **Ankh'kemet** | the Living Black Land | _ankh_ (Per-Ankhet, Ankh-Setûn) + _kemet_               |
| **Deshr'ut**   | the Red Waste         | _deshret_, reshaped                                     |
| **Ren'sesh**   | the Name Set Down     | _sesh_ (Kheperi-sesh Script)                            |
| **Khat'nu**    | the Made Body         | _khat_ (Wer'Khat, Sēker's master embalmer)              |

`Per-` stays. It is not a fresh borrowing but established corpus vocabulary — Per-Aá, Pér-Háti,
Per-Nuw, Per-Mesnu and a dozen place names — and the same holds for the ladder terms `Wab` and
`Hem'Netjer`.

Three of these earn their keep beyond sounding right. **Imnetáu** retires a genuine readability
problem: the loanword _Duat_ reads as English "dust". **Ren'sesh** puts _writing_ into the name of the
domain the whole tradition rests on, which is the doctrinal point — power is correct address, and the
address is set down. And **Sefút** is deliberately the one pure invention in the set, cognate with
nothing, which suits the domain nobody may name comfortably.

Shortcodes were re-coded to match rather than left pointing at the retired loanwords: eight
affiliations, eight skills and forty-eight `assocSkillCode` values, plus the philosophy note's table,
section headings and prose. Nothing is released, so this is the cheapest moment for it.

Link problems hold at 85 and compile errors at 95; the note count is unchanged, these being renames
rather than additions.
